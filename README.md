# Vishal Kashyap — Portfolio

My personal developer portfolio. Built with React, TypeScript, and Vite — no template, no boilerplate. Every section is a real component, every project is something I actually shipped.

## About

I'm a 3rd-year Computer Science student and Full Stack Developer based in Ghaziabad, India. This portfolio is where I keep things organized — the projects I've built, the stack I use, and where to reach me.

## Tech Stack

- **React** + **TypeScript** — component-based, typed throughout
- **Vite** — instant dev server, fast builds
- **Tailwind CSS** — utility classes alongside custom CSS where needed
- **Framer Motion** — layout animations on project/skill filters
- **Lucide React** — consistent icon set

## What's Inside

- **Hero** — intro, status, social links
- **About** — quick background
- **Projects** — filterable cards with live previews
- **Experience** — internship timeline
- **Skills** — filterable tech stack
- **GitHub Activity** — live contribution heatmap fetched from the GitHub contributions API
- **Education** — degrees and certifications
- **Contact** — email and socials

## Running Locally

```bash
npm install
npm run dev
```

Opens at `http://localhost:5173` by default (or whatever port Vite picks).

## Build

```bash
npm run build
```

TypeScript compiles first, then Vite bundles everything into `dist/`. Deploy that folder anywhere — Vercel, Netlify, Cloudflare Pages, whatever.
